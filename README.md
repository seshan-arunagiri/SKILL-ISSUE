## 🎯 About The Game

**SKILL ISSUE** is a minimalist, high-stakes avoidance game where you must survive a relentless swarm of geometric obstacles. Built from scratch with vanilla HTML5, CSS3, and the Canvas API.

### ✨ Features
- **4 Escalating Difficulties:** From Easy to Master, each level scales the speed and intensity.
- **Predictive AI Targeting:** The swarm learns to "lead" its shots based on your movement vector on harder difficulties.
- **Dynamic State Machine:** Fully integrated game loop with custom pause menus, home screens, and localized high-score tracking.
- **Synthesized Audio:** Lightweight procedural sound effects driven purely by the native Web Audio API—no external `.mp3` or `.wav` assets required.
- **Polished UX:** 60FPS precision gameplay featuring screen shakes, close-call pulses, and scaling ambient background visuals.

## 🕹️ Controls
- **Move:** `W` `A` `S` `D` or `Arrow Keys`
- **Pause:** `Escape`
